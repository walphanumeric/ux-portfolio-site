Use less, with intention

Canvas → Cream / 200 or Blue / 25 · Text → Ink · Links → Blue / 700
Callouts → Blue / 50 with Blue / 900 text; stronger highlights → Blue / 100.
Primary actions → Blue / 700 with White text; hover → Blue / 900.

Use dark text on light blue and cream surfaces; reserve White text for Blue / 700–900.
Cream / 400 is decorative, not a form-control outline.

Kept lean: purple, brown, green, yellow and gradients stay outside the core palette.
Original palette and existing styles are preserved.
